# 交互规范

本文件将原站观察转换成可实现契约。细节未亲自测试或原站未体现的部分标为复用建议。

## 交互契约

| 入口 | 输入 | 可见反馈与状态 | 验收 |
| --- | --- | --- | --- |
| 顶部导航 | 点击或键盘激活 | 当前下划线、主体切换、可链接路由 | 浏览器前进／后退有效 |
| 主题按钮 | 点击 | 所有表面、文字、边框、网格切换 | 不能只改 body 背景 |
| 分类目录 | 展开／选择 | 当前路径、子类、计数及对应图表 | 不丢层级；可返回上级 |
| 指标过滤 | 子串；可选 `/regex/` | 结果数量和相应图表；无结果反馈 | 空查询恢复结果；非法正则提示错误 |
| step／time | 选择横轴 | 横轴依据迭代序号／真实时间重新定位 | 不等间隔时间不能伪装成均匀序号 |
| linear／log | 选择纵轴 | 数据变换、轴刻度和 tooltip 一致 | 非正数据不能直接取 log |
| smoothing | 连续滑块 | 立即显示平滑程度，off 可恢复 | 不覆盖原始数据；算法与原始／平滑含义明确 |
| 图表取点 | 指针移动或触摸选择 | 竖向参考线、位置／时间、各系列精确值 | tooltip 不越屏，缺失值不编造成零 |
| 图表标题 | 点击或键盘激活 | 大图详情、完整路径、定义及统计 | Esc／关闭返回来源页 |

原站确认了主题、导航、目录下钻、标题弹层、Esc 与取点反馈。原站显示了过滤、轴类型和平滑控件；不能将未完成的行为验证写成已验证。上表是复用时应实现的契约。

## 详情层

原站的详情覆盖层仍能看到被压暗的原页面；大约占桌面 85–90% 宽，包含标题、定义、逐 run 的 last／Δ／min／max／mean／points 和大折线图。路由带指标路径，关闭后回到原目录。

复用建议：使用原生 `dialog` 或等效无障碍实现；设置可访问名称，锁定背景交互、约束焦点、Esc 关闭、关闭后恢复触发按钮焦点。手机宽度约 `calc(100vw - 24px)`，允许内容区滚动。标题按钮与图表的取点区分开，不让查看数据的点击意外打开弹层。

## 搜索与层级

子串匹配默认不区分大小写；如果提供正则，明确输入语法、捕获无效表达式，避免用户输入导致主线程卡死。200ms 左右 debounce 是复用建议。大型指标集先过滤元数据再渲染图表，只绘制当前可见图。

应明确搜索是全局还是当前目录：在结果标题显示范围。过滤不应默默跳离当前位置；清空查询恢复可预期结果。目录选择、结果数和图表不能互相矛盾。路径稳定时适合 URL hash 或现有 router；无需引入第二套路由库。

## 图表与数据语义

- 维护唯一的 `seriesId → color` 映射；排序、过滤、主题切换不能换色。
- 数值格式按单位与数量级选择；tooltip 提供足够精度。差值有明确的基准，不能把“上升”自动写成“更好”。
- 平滑优先使用明确的 EMA，例如 `s[i] = a*y[i] + (1-a)*s[i-1]`。滑块增大应对应更强平滑；off 完整恢复原序列；原始值依然可查。
- 对数轴只适用于正数；禁用、解释性空状态或显式 symlog 均可。不能静默删除负数、画成零或添加未说明的偏移。
- 不同 run 在同一步或同一时间附近的比较应说明对齐策略，不按数组下标假定相等。缺数据保留缺口，重启或异常给出标记。
- 如果只有静态样例，不放呼吸的“live”状态，不让随机数据自动变化来模拟接入。样例可以演示控件，但必须明示数据性质。

## 持续更新

原站通过费用、时钟、步骤、公告与日志传递“正在运行”，不是依靠大片动画。复用建议：区分 last successful update、loading、reconnecting、stale、error；请求失败保留最后一次成功数据并标明时间；更新不重置搜索、轴设置、目录与弹层。

后台 tab 减少工作量，取消过期请求，避免多个轮询重叠。日志批量增量插入；用户离开底部或顶部追踪位置后，不强制滚动，提供“新记录”提示。

## 动效与键盘

复用建议：控件状态 100–160ms，弹层淡入最多约 160ms；频繁更新数值不做滚动计数，不让卡片跳动。`prefers-reduced-motion` 下去掉非必要过渡。focus-visible 使用 2px 清晰轮廓；可点击标题必须是按钮或链接。图表 tooltip 不应成为唯一读取途径，至少提供详情中的数据表或可访问的数值摘要。

## 随附样例的边界

`assets/starter/` 实现：主题切换、概览／指标／说明路由、分类筛选、子串／正则过滤、步数／时间横轴、线性／对数纵轴、EMA 平滑、指针取点、详情 dialog、键盘关闭、可读取数据表和窄屏布局。

样例使用确定性的虚构数据，不连接原站，不声称实现原站所有目录、采样日志、批次组成、网络轮询或生产级大数据性能。需要这些功能时按实际任务实现。
