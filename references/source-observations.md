# 来源与观察边界

来源：<https://mimo.xiaomi.com/rl/>。观察日期：2026-09-17。页面标题：`mimo-v2.6 RL`。浏览器桌面约 1280×720，窄屏视口 390×844。页面数据在更新，以下不把运行数值当作长期事实。

## 直接看到与操作确认

- 深色概览：sticky 顶栏，overview／metrics／about，右侧费用、多时区时钟及主题图标。公告列表在前，随后为两个宽运行状态面板，下面有 benchmark、指标网格、采样日志、来源表和批次组成。
- 每个运行面板具有身份色点、步骤、运行时长、阶段进度，以及六个统计单元。图表比较使用橙色和蓝色。
- 点击 metrics，然后点击 dynsam 分类：左侧出现树状目录及计数；主体为面包屑、子分类按钮、三列图表；URL 从 `#metrics` 变为 `#metrics/dynsam`。
- 图表绘图区点击位置出现数据 tooltip 与竖线；点击 `avg@n` 标题打开大图弹层。弹层有完整指标名、定义、两行运行统计及大图；URL 变为 `#chart/dynsam%2Favg%40n`。
- Esc 关闭弹层并恢复 `#metrics/dynsam`。
- 主题按钮切换到白色主题；读取切换前后根元素 computed style 得到 design-system.md 的 token 表。
- 控件可见：step／time、linear／log、smoothing slider；搜索框提示支持 substring 或 `/regex/`。出现了无结果状态。搜索输入期间有输入干扰，因此没有把过滤正确性、正则执行或轴／平滑算法记为已验证。
- about 为左对齐的小标题、两段简短说明及链接，底部细线页脚；没有巨大 hero。
- 390px 窄屏：顶栏隐藏费用及时钟，概览统计改为两列，长状态信息换行；metrics 工具栏多行，目录在图表上方成为有高度限制的滚动区。

## 测量与推导的区别

- **实测**：根 CSS 变量、字体声明、13.5px 基础字号、12.5px 控件字号、48px 桌面导航 token、6px 卡片圆角、10px 图表网格 gap、卡片 padding、170px 小图绘图区高度。
- **视觉观察**：橙蓝系列、低对比网格、细折线、末端圆点、下划线导航、内部细分隔、几乎无装饰阴影。
- **复用建议**：720／1100px 断点、动画时长、对比度改进、焦点管理、触摸目标扩大、请求重试和性能策略。它们用于提高成品质量，不声称来自原站源码。
- **未验证**：原站具体图表库、后端协议、实际平滑公式、全套键盘语义、主题持久化、精确 CSS 断点、全部交互边界。
