# 设计系统：紧凑的科学观测台

## 美学的因果关系

原站给人的感觉是「正在使用的研究工具」。完整的路径名、少修饰的数字、持续可见的状态和规则排列的曲线让内容可信。大量中性色压低装饰噪声，橙蓝只标识比较对象；模块边界靠细线表达，不靠阴影制造层级。

高信息密度不等于全部挤小：组内紧、组间松；同类对象尺寸一致；标题与数值对齐；重要状态在上，长尾指标下钻；同一页可以同时存在密集图表与大片空白。

## 字体与尺寸

| 元素 | 原站实测或推荐 |
| --- | --- |
| UI 字体 | 实测 `Inter, -apple-system, "Segoe UI", system-ui, Helvetica, Arial, sans-serif` |
| 数据字体 | 实测 `ui-monospace, "SF Mono", Menlo, Consolas, "Liberation Mono", "DejaVu Sans Mono", monospace` |
| 基础字号／行高 | 实测 `13.5px / 1.45` |
| 紧凑控件字号 | 实测 `12.5px` |
| 注释、刻度、数据路径 | 复用建议 `11–12px`，必要信息使用次文字色而不是最弱色 |
| KPI 值 | 复用建议 `20px / 1.2`，600–650 字重 |
| 常规页面标题 | 复用建议 `18–20px`，避免营销式超大标题 |
| 导航高度 | 实测桌面 token `48px` |
| 卡片圆角 | 实测 `6px`；小图标按钮 `4px` |
| 桌面主区 padding | 实测 `22px 20px 40px` |
| 图表网格 gap | 实测 `10px` |
| 图表卡 padding | 实测 `10px 12px 8px` |
| 公告卡 padding | 实测 `12px 14px` |
| 小图主图区高度 | 实测 `170px`（不含卡片标题、图例等） |

中英文混排时给 UI 字体追加 `"PingFang SC", "Microsoft YaHei"`；中文正文无需强行等宽。金额、百分比、时间与单位对齐；单位小一档，关键值不能随更新跳动。路径过长可保留尾部、显示完整 tooltip 或在详情显示全名，窄屏不能截掉关键值。

原站最低灰度与极小标签可能不适合所有屏幕。正文和关键说明以至少 4.5:1 对比度验收，交互边界及 focus 以可辨识为准；可把必要的弱文字提升到次文字色。不要以「还原」为由保留不可读文字。

## 组件配方

### 顶栏

左侧 2–4 个简短文本入口，当前项 2px 下划线；右侧是与业务有关的总量或更新时间，主题切换为小型图标按钮。原站桌面有多时区时钟；只在跨地域操作确有价值时复用。导航 sticky，底部 1px 分隔。不要自行增加大型品牌栏。

### 运行状态面板

一整个宽面板。第一层包含颜色点、对象名、文字状态、阶段号、经过时间和细进度条；第二层使用共享边界的 KPI 网格。六项统计在桌面排六列，移动端两列三行。颜色点用于识别 run，状态另有文字。进度未知就显示阶段文本，不编造百分比。

### 图表卡

标题是能打开详情的轻量按钮；左上是短指标名／完整路径，右上按 run 排列「色点 + 最新值 + Δ」。卡内主图区保持统一高度。折线约 1.5–2px、末端点约 3px、水平网格 1px；精确值可查询，无大面积渐变填充、无装饰曲线平滑。小图可隐藏普通数据点来减少噪声。

坐标轴显示单位。需要比较幅度的同类图使用相同尺度；不同单位不得为视觉整齐强塞同轴。自动缩放时保留真实刻度，不暗示零基线。差值明确比较基准：前一点、首步、基线或上周期。

### 目录探索

桌面侧栏约 240–260px，主区 `minmax(0,1fr)`。目录用窄行、三角展开符和右对齐计数；选中行为低对比底色。主区先显示路径面包屑和数量，再显示子分类的小型矩形按钮和图表网格。没有指标的目录可以是空白，不放无关插图。

### 日志与表格

日志时间列固定宽度，正文伸缩，状态或阶段靠右；细水平线分行。表格使用紧凑单元格，标签左对齐、数字右对齐；行内进度条作为数据背景而非抢眼的独立组件。真实更新应显示最后成功时间与连接状态。

## 响应式复用建议

以下断点是原创实现建议，不是已读取的原站 CSS 断点：

- ≥1100px：六列 KPI、三列小图、目录侧栏。
- 720–1099px：三列 KPI、两列小图，较窄目录或可收起目录。
- <720px：两列 KPI、单列小图；工具栏换行，非必要顶栏状态收起；目录变成上方有高度上限的可滚动区域或可访问的抽屉。
- 页面左右留白从 20px 降为 12px；触摸控件可扩大到 36–44px，但保留紧凑桌面版本。
- 图表容器可缩放，表格自己横向滚动。不给 body 固定最小宽度。

## 容易偏离的样子

避免把它变成霓虹赛博屏、金融交易终端仿皮、营销 SaaS 模板或巨型 KPI 展示墙。常见偏差包括：16–24px 大圆角、每卡一个图标、彩色渐变背景、40px 大标题、发光曲线、普遍 24px 以上组内留白、所有涨跌都强行红绿、让无关的动画与实时数字竞争注意力。
